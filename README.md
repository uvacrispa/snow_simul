# snow_simul

A small SFML 3 snow simulation.
Snowflakes drift down under gravity and wind, settle on the ground, and gradually form soft snowdrifts.

## Demo

https://github.com/user-attachments/assets/914f3e59-a9f8-4dd1-8ae6-50cae04cb5c2

## Build and run

CMake and SFML 3 must be installed.

```sh
cmake -S . -B build
cmake --build build
./build/snow_simul
```
